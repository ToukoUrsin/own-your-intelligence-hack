# Returns and refunds

- 30-day returns for unused items in original packaging. Customer pays return shipping ($8 prepaid label deducted from the refund) unless the item arrived damaged or wrong.
- Opened grinders and kettles: returnable within 30 days only if defective (see warranty).
- Refunds go to the original payment method within 3–5 business days after the warehouse receives the return.
- Damaged on arrival: ask for one photo of the item and box; no return needed for items under $80; we reship or refund immediately.
- Wrong item sent: we send the correct item right away and include a prepaid label for the wrong one.
- Subscriptions (beans): can be paused, skipped or cancelled any time before the next billing date; no refunds for shipped bean boxes except quality issues.
