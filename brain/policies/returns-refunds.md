# Returns and refunds policy

- Return eligibility depends on membership (`policies/membership`). Returns for stain, wrong color or wrong size follow `procedures/product-defect-return-*`.
- Return methods (`update_order` value): **by mail** (we email a prepaid label), **in store**, or **drop off center**.
- Refund methods (`record_reason` refund target): **credit card** on file, **add value** (account credit), **gift card** (mailed, needs address), **paper check** (mailed, needs address).
- Refunds show up 5–7 business days after they are issued. If a refund is older than that, notify the purchasing department (`procedures/product-defect-refund-status`).
- If a customer does not know the amount, the default refund amount is $50.
