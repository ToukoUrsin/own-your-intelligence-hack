# Returns and refunds

- 30-day returns for unused items in original packaging. Customer pays return shipping ($8 prepaid label deducted from the refund) unless the item arrived damaged or wrong.
- Opened grinders and kettles: returnable within 30 days only if defective (see [[policies/warranty]]).
- Cancelled before shipping: full refund immediately, no fee.
- Refunds go to the original payment method. We send the refund when the warehouse receives the return (usually 1–2 days after the carrier delivers it). Banks and cards then take 3–5 business days, PayPal 1 day.
- Damaged on arrival: ask for one photo of the item and box; no return needed for items under $80; we reship or refund immediately.
- Wrong item sent: we send the correct item right away and include a prepaid label for the wrong one.
- Duplicate or unauthorized charge: refund the duplicate immediately once confirmed in the order's payment record.
- Subscriptions (beans): can be paused, skipped or cancelled any time before the next billing date; no refunds for shipped bean boxes except quality issues.
- Discount codes cannot be applied after an order is placed; we refund the difference once within 7 days if a public code existed at purchase time.
