# Promo codes

- Promo codes are valid for **7 days** after they are issued. A code older than 7 days is *out of date*; a newer code that fails is *invalid* (check the system first with `check_system`).
- Gold, Silver and Bronze members get a new code (`promo_code`) even if the old one failed for their own reason. Guests do not.
- Price match: if an item got cheaper since yesterday, or a competitor sells it cheaper, issue a promo code for the difference (`procedures/purchase-dispute-bad-price-*`).
