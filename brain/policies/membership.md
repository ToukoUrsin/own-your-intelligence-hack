# Membership levels and privileges

Levels: **Gold**, **Silver**, **Bronze**, **Guest** (not a member). Look the level up with `pull_up_account` or `membership`.

| Situation | Gold | Silver | Bronze | Guest |
|---|---|---|---|---|
| Returns | unlimited | within 6 months, or with receipt, or in original packaging | within 90 days, or with receipt, or in original packaging | within 30 days, or with receipt |
| Unexplained / extra fee on order | removed | removed | stays (customer error) | stays |
| Subscription late payment extension | always | only if 1 day late | no | no |
| Subscription bill dispute | always refunded | refunded if the wrong amount is under $10 | depends on `check_system` | depends on `check_system` |
| Mistimed billing (already returned / never bought) | credit given even if the system says customer error | only if company error | only if company error | only if company error |
| Invalid / expired promo code | new code | new code | new code | nothing we can do |
| Shipping fee on delayed order already shipped | credit back | credit back | credit back | nothing we can do |
| Out-of-stock item | ship ASAP in separate order, no shipping fee (Gold/Silver) | same | — | — |
