### Description draft
Support that gets cheaper with every ticket. Customers message a support agent inside QM (our local fork of YC's harness). The company's policies and procedures live in GBrain. The first time a kind of request comes in, the agent explores: searches the brain, calls the Shopify store, resolves it. Memorable saves that path. Next time, a River-trained router standardizes the messy request and matches it to the saved path, and the agent replays it in a few steps. Our QM fork adds a Paths panel: recalled vs explored per message, steps, time, cost, and the learning curve over hundreds of replayed tickets.
