States say what happened

RunningWork is being executed. ResolvedThe requested outcome has evidence. Needs reviewA named decision is waiting for a person. FailedAn attempt failed; show the recovery action. UnavailableNo trustworthy result is available.

Empty, loading and error guidance

Keep the last complete result during refresh. Explain an empty library with one setup action. Pair errors with a reason and a specific retry. Missing cost is “Cost unavailable,” never $0.
